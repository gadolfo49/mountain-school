# Ejecución inicial

Este prototipo es una aplicación Next.js aislada dentro de la carpeta agente-journals.

1. Desde la raíz de esta carpeta: `npm install`.
2. Ejecutar `npm run dev`.
3. Abrir `http://localhost:3000`.

**Advertencia**: es una maqueta funcional de sesión sin autenticación ni persistencia. No debe exponerse como servicio privado ni usarse para materiales reservados.

La biblioteca de Google Drive fue creada por separado y su enlace sirve para acceder manualmente; el código aún no tiene un conector Drive ni permisos de lectura. Configurar repositorio independiente privado, base de datos, autenticación y permisos antes de un despliegue de uso real.
